# Historia — тренажёр ЕГЭ по истории

Сайт работает без установки и сборки.

Для публикации загрузите содержимое этой папки в корень репозитория paveltupikin/historia. Затем в GitHub откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку / (root), нажмите Save.

Адрес после публикации: https://paveltupikin.github.io/historia/

Файл .nojekyll скрытый; сайт работает и без него.

База: 1092 даты и события, 644 личности, 976 терминов, 52 восстания. Материалы из предоставленных документов по пособию Т. В. Черниковой и др.; охват до 1991 года. Прогресс сохраняется в браузере.
